## Why

Аудит amster2 нашёл письма, которые FFIDO декодирует неверно. Некоторые JAM-базы содержат разные кодировки, поэтому нужна поправка для конкретной записи, с возможностью вернуть прежнее чтение.

## What Changes

- Добавить опциональный файл проверенных поправок чтения для отдельных писем эх. Поправка действует при совпадении базы, номера, отпечатка исходной записи и прежнего декодера.
- Использовать общий результат выбора кодировки для выдачи заголовков и тел, поиска, ответов, вложений и технических данных. Сохранять исходный CHRS в технических данных.
- Подготовить пакет по результатам аудита amster2. Спорные письма и письма с невалидной UTF-8 остаются на ручной проверке.
- Предусмотреть отключение файла и проверку отката на изолированной копии. Рабочие JAM, HPT, SQLite и gRPC-контракт сохраняются.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `jam-storage` — точечные обратимые поправки к выбору кодировки чтения с проверкой исходной записи.

## Impact

Backend FFIDO, конфигурация запуска, диагностика и тесты JAM. Файл поправок содержит идентификаторы записей и отпечатки, хранится отдельно от репозитория. Развёртывание на amster2 выполняется отдельной операторской операцией.
