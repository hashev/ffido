# Proposal

## Why

Пользователю требуется готовое оформление писем без ручного переноса шаблона GoldED. Сейчас отсутствие настройки и сброс включают прежнее оформление, а предложенный адаптированный шаблон приходится вставлять самостоятельно.

## What Changes

- Использовать предложенный в чате адаптированный английский шаблон GoldED по умолчанию для новых писем, обоих видов ответа и пересылки.
- Показывать этот же текст в настройках при отсутствии пользовательской настройки; сброс возвращает его, а «Вставить пример» использует тот же источник текста.
- Сохранять существующие пользовательские шаблоны, включая явно сохранённый пустой текст; не записывать встроенный шаблон поверх них при обновлении.
- Сохранить текущую диагностику повреждённых настроек и возможность явно выбрать прежнее штатное оформление при ошибке.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `message-templates`: встроенный шаблон по умолчанию, его отображение и восстановление при сбросе, сохранение пользовательских переопределений.

## Impact

Затронут только Flutter-клиент `apps/frontend/`: настройки шаблонов, панель настройки, создание черновика и тесты. HTTP API, сервер, формат сохранённых настроек и зависимости не меняются. Новое оформление получают также существующие установки без сохранённого шаблона.
