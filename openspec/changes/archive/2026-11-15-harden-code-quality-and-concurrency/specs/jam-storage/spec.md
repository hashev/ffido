# Spec Delta

## ADDED Requirements

### Requirement: Восстановление при изменении формата области
Если область незавершённой операции отсутствует либо больше не поддерживает JAM, восстановление SHALL завершаться контролируемой ошибкой с сохранением операции для диагностики. Процесс SHALL не падать и не создавать, не изменять и не подменять файлы новой области.

#### Scenario: Прежний ID с неподдерживаемым форматом
- **WHEN** журнал содержит незавершённую JAM-операцию, а текущая область того же ID имеет формат Squish или MSG
- **THEN** восстановление возвращает контролируемый отказ, сохраняет сведения об операции и не обращается к отсутствующим JAM-файлам

#### Scenario: Область удалена
- **WHEN** область незавершённой операции отсутствует в текущем каталоге
- **THEN** восстановление сообщает контролируемую ошибку без падения и без записи в другую область

#### Scenario: Ошибка сохранения состояния восстановления
- **WHEN** невозможно устойчиво записать состояние отказавшей операции
- **THEN** ошибка хранилища не скрывается, запуск записи в затронутую базу не разрешается и исходные файлы сохраняются

### Requirement: Прерывание длительного чтения JAM
Длительное чтение и преобразование существующего сообщения SHALL соблюдать общий deadline и отмену запроса без продления бюджета. После прерывания сервер SHALL освобождать ресурсы доступа к базе, возвращать контролируемую ошибку и позволять следующий запрос. Исходные JAM-данные SHALL не изменяться из-за прерванного чтения.

#### Scenario: Отмена во время преобразования тела
- **WHEN** запрос чтения большого сообщения отменён после начала преобразования его кодировки
- **THEN** сервер прекращает дальнейшую обработку тела и освобождает доступ к базе, не ожидая преобразования всего сообщения
- **AND** новый запрос может получить то же сообщение целиком

#### Scenario: Исчерпание deadline при нормализации текста
- **WHEN** общий deadline чтения истёк во время нормализации большого тела
- **THEN** запрос завершается ошибкой deadline без нового бюджета для следующего этапа и без частичного успешного тела

#### Scenario: Граница блока и перенос строки
- **WHEN** CRLF пересекает границу внутренних блоков обработки корректного сообщения
- **THEN** полное чтение сохраняет прежние байты Unicode и нормализует CR и CRLF в один LF без потери текста
