# Spec Delta

## Purpose

Обеспечивает предсказуемую обработку ответов REST-сервера и сохранение диагностики ошибок для клиентских сценариев.

## ADDED Requirements

### Requirement: Успешные ответы
Клиент SHALL принимать JSON-объекты в UTF-8 и пустые успешные ответы, возвращая для пустого тела пустой объект.

#### Scenario: Нет тела ответа
- **WHEN** сервер возвращает 204 или другой 2xx с пустым телом
- **THEN** операция завершается успешно с пустым объектом

#### Scenario: Русский текст без charset
- **WHEN** JSON-объект содержит русский текст в UTF-8 без charset в заголовке
- **THEN** текст декодируется без искажений

### Requirement: Диагностика ошибок
Клиент SHALL сохранять статус и endpoint HTTP-ошибки независимо от формата тела; 401, 404, 422 и все 5xx SHALL иметь соответствующий тип ошибки.

#### Scenario: HTML вместо JSON ошибки
- **WHEN** сервер возвращает 503 с HTML или пустым телом
- **THEN** клиент сообщает серверную ошибку со статусом 503 и endpoint

#### Scenario: Ошибки полей
- **WHEN** сервер возвращает 422 с errors как JSON-объектом списков строк
- **THEN** клиент сообщает ошибку валидации с сохранёнными списками ошибок полей

#### Scenario: Неизвестный серверный статус
- **WHEN** сервер возвращает 504
- **THEN** клиент сообщает серверную ошибку со статусом 504

#### Scenario: Некорректное успешное тело
- **WHEN** успешный ответ содержит повреждённый JSON или массив вместо ожидаемого объекта
- **THEN** клиент сообщает контролируемую ошибку формата ответа
