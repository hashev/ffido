# Proposal

## Why

Сейчас редактор FFIDO отправляет письмо только в одну эху. Нужна публикация одного текстового сообщения в несколько выбранных эх с явным указанием исходной эхи и адресатов кросспостинга, как в GoldED+.

## What Changes

- Меню «⋯» редактора с пунктом «Кросспостинг», списком доступных для публикации эх, поиском и независимыми галочками.
- Исходная эха остаётся обязательной; дополнительные эхи выбираются без дублей, выбор сохраняется при поиске и перелистывании списка.
- В начало тела каждой копии добавляется общий блок `* Originally in …` и `* Crossposted in …` по формату GoldED+.
- Сервер выполняет групповую отправку с проверкой прав, отдельной FTN-идентичностью каждой копии и устойчивым продолжением после частичного сбоя без повторной публикации сохранённых копий.
- Кросспостинг охватывает новые письма, ответы и пересылки в эхи. По согласованию с пользователем поддерживаются только текстовые сообщения: кросспостинг и прикрепление UUE-файла взаимоисключающие.

## Capabilities

### New Capabilities

- `echo-crossposting`: выбор нескольких эх, видимая атрибуция и надёжное локальное сохранение копий текстового письма.

### Modified Capabilities

Нет. Обычная отправка, правила ответа в исходной эхе, разграничение доступа и UUE сохраняют действующие требования; особенности дополнительных копий определяются новой возможностью.

## Impact

- Flutter: `apps/frontend/lib/pages/message_screen.dart`, новый экран множественного выбора рядом с `forward_destination.dart`, репозитории сообщений/конференций и транспорт.
- Общий API: `contracts/ffido/v1/ffido.proto`, генерация Dart-контракта штатным `tools/proto/generate.sh`; новый RPC для групповой отправки без изменения семантики `CreateMessage`.
- C++: gRPC-адаптер, `MessageService`, метаданные SQLite и восстановление операций JAM; используются текущие механизмы доступа, кодирования, блокировок и устойчивой записи.
- Тесты клиента, серверных сервисов, gRPC и восстановления; документация API и отправки. Новые зависимости, изменение маршрутизации HPT и обновление toolchain не требуются.
- Не входят: UUE-кросспостинг, изменение уже опубликованных писем, команды XC/XP в тексте, маски/скрытые адресаты GoldED и обещание сетевой доставки.
