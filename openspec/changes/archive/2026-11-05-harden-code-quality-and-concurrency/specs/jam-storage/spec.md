# Spec Delta

## ADDED Requirements

### Requirement: Восстановление при изменении формата области
Если область незавершённой операции отсутствует либо больше не поддерживает JAM, восстановление SHALL завершаться контролируемой ошибкой с сохранением операции для диагностики. Процесс SHALL не падать и не создавать, не изменять и не подменять файлы новой области.

#### Scenario: Прежний ID с неподдерживаемым форматом
- **WHEN** журнал содержит незавершённую JAM-операцию, а текущая область того же ID имеет формат Squish или MSG
- **THEN** восстановление возвращает контролируемый отказ, сохраняет сведения об операции и не обращается к отсутствующим JAM-файлам

#### Scenario: Область удалена
- **WHEN** область незавершённой операции отсутствует в текущем каталоге
- **THEN** восстановление сообщает контролируемую ошибку без падения и без записи в другую область

#### Scenario: Ошибка сохранения состояния восстановления
- **WHEN** невозможно устойчиво записать состояние отказавшей операции
- **THEN** ошибка хранилища не скрывается, запуск записи в затронутую базу не разрешается и исходные файлы сохраняются
