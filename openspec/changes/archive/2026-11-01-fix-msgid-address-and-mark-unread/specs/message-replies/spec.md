# Spec Delta

## ADDED Requirements

### Requirement: Адрес автора из доменного MSGID
При отсутствии OADDRESS сервер SHALL извлекать числовой FTN-адрес из начала корректного MSGID, допускающего необязательный домен после `@`. Отображение from_address и адресация ответа SHALL использовать одинаковый результат. Полный MSGID SHALL сохраняться для REPLY без изменения оригинала. Непустой OADDRESS SHALL сохранять приоритет; общая проверка адресов профиля и явных адресатов не ослабляется.

#### Scenario: Исходное письмо без OADDRESS
- **WHEN** исходное письмо не содержит OADDRESS и имеет MSGID `2:5001/100@fidonet 6ae67e72`
- **THEN** API возвращает from_address `2:5001/100`, редактор показывает этот адрес, обычный ответ успешно проходит проверку адреса родителя
- **AND** новое письмо адресовано автору исходного, а REPLY содержит полный `2:5001/100@fidonet 6ae67e72`

#### Scenario: Поинт и обычный MSGID
- **WHEN** адрес в MSGID имеет вид `2:5001/100.7@fidonet` либо `2:5001/100.7` и после него есть непустой идентификатор
- **THEN** извлекается `2:5001/100.7`; точечная часть сохраняется, адрес с `.0` канонизируется по действующим правилам

#### Scenario: Приоритет явного адреса
- **WHEN** OADDRESS содержит `2:1/2`, а корректный MSGID начинается с `2:3/4@fidonet`
- **THEN** адресом автора остаётся `2:1/2`, доменный MSGID не подменяет явный адрес

#### Scenario: Повреждённый MSGID
- **WHEN** OADDRESS отсутствует, а MSGID содержит пустой домен, несколько `@`, запрещённые символы домена, некорректный числовой адрес либо не содержит непустого идентификатора после адреса
- **THEN** сервер не выдумывает адрес и не берёт его из тела, Origin, REPLY или профиля; ответ без валидного адреса родителя отклоняется без записи

#### Scenario: Чтение и безопасность профиля
- **WHEN** сервер читает письмо с доменным MSGID и пользователь затем отвечает на него
- **THEN** оригинальные JAM-файлы и MSGID остаются неизменными
- **AND** такой MSGID не позволяет войти с доменным адресом вместо числового либо обойти правила явного адресата, владельца или прав доступа
