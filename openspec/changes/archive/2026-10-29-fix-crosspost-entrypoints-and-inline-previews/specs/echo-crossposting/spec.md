# Spec Delta

## MODIFIED Requirements

### Requirement: Выбор эх из редактора
Редактор текстового письма в эху MUST предоставлять меню «⋯» с пунктом «Кросспостинг». Список MUST поддерживать поиск и галочки для нескольких дополнительных эх. Исходная эха MUST оставаться обязательной, исключаться из дополнительных адресатов и явно отображаться. Выбор MUST применяться только после подтверждения. Меню MUST быть доступно при открытии из главного списка, закладок и истории в текущей сессии.

#### Scenario: Выбор нескольких адресатов
- **WHEN** пользователь создаёт письмо, ответ или пересылку в эху и отмечает две дополнительные эхи
- **THEN** после подтверждения редактор показывает исходную эху и обе выбранные эхи
- **AND** повторное открытие списка сохраняет галочки; снятие всех галочек возвращает обычную отправку

#### Scenario: Отмена выбора
- **WHEN** пользователь изменяет галочки и закрывает список без подтверждения
- **THEN** редактор сохраняет прежний набор адресатов

#### Scenario: Смена назначения пересылки
- **WHEN** пользователь меняет основную эху пересылки
- **THEN** новая основная эха исключается из дополнительных адресатов, остальные выбранные эхи сохраняются

#### Scenario: Штатные точки входа
- **WHEN** пользователь открывает доступную для публикации эху из главного списка, закладок или истории и создаёт текстовое письмо либо ответ
- **THEN** меню «⋯» активно, пункт «Кросспостинг» открывает список дополнительных эх текущего сервера и пользователя

#### Scenario: Межэховый переход
- **WHEN** пользователь перешёл при чтении к следующей эхе с непрочитанными и открыл редактор
- **THEN** основная эха и права соответствуют новой эхе, а выбор дополнительных эх доступен в той же сессии

#### Scenario: Другая сессия и ограничения
- **WHEN** во время работы редактора или выбора адресатов меняется пользователь либо сервер
- **THEN** прежний каталог не используется для новой сессии и незавершённый выбор закрывается по действующим правилам
- **WHEN** письмо относится к личной или служебной области либо содержит UUE-вложение
- **THEN** действующие ограничения кросспостинга сохраняются
