## MODIFIED Requirements

### Requirement: Матрица доступных пакетов
Успешный выпуск SHALL содержать клиент для macOS ARM64, Windows x86_64, Android universal и Linux x86_64, сервер для Linux x86_64/macOS ARM64 и перечень поддерживаемых архитектур и минимальных ОС. Серверный пакет SHALL включать admin, helper, wrapper и безопасный пример конфигурации. Каждый пакет SHALL содержать необходимые распространяемые зависимости либо явно документировать установку внешних зависимостей.

#### Scenario: Загрузка на чистой системе
- **WHEN** пользователь скачивает пакет для заявленной платформы
- **THEN** он может установить и запустить его по инструкции без каталогов и библиотек разработчика

#### Scenario: Отсутствующая платформа
- **WHEN** один обязательный пакет не собран или не прошёл проверку
- **THEN** выпуск не становится публичным как завершённый набор

#### Scenario: Новый выпуск без Intel
- **WHEN** публикуется новый полный выпуск
- **THEN** ожидаются ровно шесть пакетов указанной матрицы и контейнер linux/amd64; отсутствие macOS x86_64 не считается неполнотой

#### Scenario: Исторические версии
- **WHEN** пользователь обращается к прежнему подписанному релизу с macOS x86_64
- **THEN** его файлы и подписи не изменены, валидаторы продолжают распознавать историческую архитектуру

### Requirement: Проверки до слияния
PR в master SHALL проходить анализ и тесты клиента, сборку и тесты backend на поддерживаемых ОС без macOS Intel, проверку общего контракта и сборку клиентских пакетов на четырёх платформах. Обязательные интеграционные проверки SHALL использовать синтетические данные и совместимый HPT без доступа к рабочей ноде. Пропуск обязательной проверки SHALL не считаться успехом.

#### Scenario: Регрессия Windows
- **WHEN** клиент не собирается на Windows, хотя Linux-проверки успешны
- **THEN** общий обязательный результат запрещает слияние

#### Scenario: Нет тестового HPT
- **WHEN** обязательная HPT-проверка не выполнена из-за отсутствия зависимости
- **THEN** CI сообщает ошибку вместо зелёного результата с пропуском

#### Scenario: Матрица без Intel
- **WHEN** запускаются PR, выпуск master, стабильный выпуск или прогрев зависимостей
- **THEN** задания macOS Intel не создаются, macOS ARM и проверки остальных платформ сохраняются без сокращения покрытия

#### Scenario: Достоверные длительности
- **WHEN** устанавливаются зависимости Flutter и выполняются его тесты
- **THEN** отчёт различает эти этапы, не приписывая время тестов загрузке зависимостей

## ADDED Requirements

### Requirement: Обновление только совпадающей архитектуры
После исключения Intel из новых выпусков установке macOS x86_64 SHALL не предлагаться пакет ARM64 вместо отсутствующего Intel-пакета. Новая матрица SHALL быть согласована между workflow, перечнем ожидаемых пакетов, подписанными метаданными и документацией. Старые публичные артефакты SHALL оставаться неизменными.

#### Scenario: Проверка обновления Intel-установки
- **WHEN** Intel-клиент проверяет новый выпуск без подходящей архитектуры
- **THEN** ARM64 не предлагается как совместимое обновление и исторический Intel-пакет не переписывается

#### Scenario: Отсутствующий обязательный пакет
- **WHEN** в новом выпуске отсутствует один из шести обязательных пакетов либо контейнер
- **THEN** публикация блокируется прежними проверками полноты
