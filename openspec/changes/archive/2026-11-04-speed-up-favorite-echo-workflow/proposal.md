# Proposal

## Why

При 514 областях клиент ждёт полный каталог со статистикой перед показом, повторяет обход после изменения закладки и возврата из чтения. Пользователю нужен быстрый ежедневный вход в избранные эхи и независимый лёгкий каталог для их выбора; macOS Intel дополнительно удлиняет выпуск.

## What Changes

- Открывать избранное по умолчанию без загрузки полного каталога; пустое избранное предлагает «Выбрать эхи».
- Унифицировать карточки, отступы, действия и состояния загрузки избранного и общего списка. Сохранить точные непрочитанные в избранном.
- Показывать полный каталог постранично, без чтения JAM-статистики и без счётчиков. Сохранить группы типов областей; эхи сортировать по имени без приоритета непрочитанных.
- Изменять избранность строки только после подтверждения API, без перезагрузки каталога; сохранять поиск, прокрутку и загруженные страницы при переключении вкладок.
- После чтения обновлять затронутые области, не перечитывая каталог. Рассчитывать статистику избранного только для запрошенной страницы; при добавлении закладки проверять права без подсчёта сообщений.
- **BREAKING (поведение UI)**: межэховый переход «Следующее» использует только избранное для всех источников открытия. После неизбранной эхи начинается с первой избранной по алфавиту; пустое избранное завершает межэховый переход. Порядок общего списка больше не зависит от непрочитанных.
- **BREAKING (новые дистрибутивы)**: убрать macOS Intel из клиентской/серверной матрицы PR и релизов, прогрева и обязательных пакетов; сохранить macOS ARM и все остальные платформы. Исторические релизы не менять.

Все три варианта UI согласованы пользователем 04.11.2026. Удаление Intel следует исходному запросу: достоверного решения задержки через кеш зависимостей не найдено.

## Capabilities

### New Capabilities

Нет: используются существующие возможности каталога, чтения и выпуска.

### Modified Capabilities

- `conference-browsing`: лёгкий каталог, серверный устойчивый порядок и страницы, общий вид списков, сохранение состояния и изоляция кеша.
- `message-access`: избранное по умолчанию, подтверждаемые локальные изменения, точечная актуализация, бюджет статистики страницы и единый источник межэховой навигации.
- `release-distribution`: матрица новых пакетов и проверок без macOS Intel, сохранение старых артефактов.

## Impact

- `apps/frontend/`: reader_app, PersonalConferences, ConferenceCard, репозитории, навигация MessageScreen, модели и тесты.
- `apps/backend/`: ConferenceService, gRPC-обработчики списков/закладок и интеграционные тесты.
- `contracts/ffido/v1/ffido.proto` и генерируемые Dart-привязки: совместимое расширение gRPC для лёгкого каталога и фильтра избранного; прежние запросы сохраняют поведение.
- `.github/workflows/`, `scripts/release/settings.json`, проверки состава пакетов, README и документация выпуска.
- Без новых зависимостей, смены toolchain, изменения JAM/SQLite-схемы, отправки тестовых FTN-писем или изменения работающей ноды. Сам выпуск и развёртывание в этот proposal не входят.
