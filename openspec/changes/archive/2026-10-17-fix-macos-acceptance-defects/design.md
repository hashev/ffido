# Design

## Context

См. proposal.md. Установленная SMAPI в ConvertXmsgToJamHdr сохраняет OADDRESS/DADDRESS только для не-echo; scan переписывает заголовки и удаляет поля. SQLite operations уже содержит durable header_append с первоначальными подполями, идентичностью и состоянием commit. Flutter IndexedStack создаёт историю заранее, но не перезагружает её при выборе вкладки.

## Goals / Non-Goals

Исправить DEF-001–003 без нового формата JAM, новых FTN-кладжей, схемы SQLite или изменения gRPC. Не менять HPT, его рабочую конфигурацию и не писать в рабочие базы. Проверка pack/renumber не входит в этот фикс: резервный адрес нельзя переносить на другую идентичность.

## Decisions

- При пустом DADDRESS читать только header_append committed operations, отбирая conference/generation/message_number/ftn_msgid. Разбирать длины с bounds checks и проверять FTN-адрес. Это восстанавливает уже потерянные адреса, не создаёт второе хранилище и использует существующую атомарность prepare/commit/recovery. Не выводить адрес из REPLY, поскольку это не доказывает явное назначение. Не добавлять собственный kludge в экспортируемый FTN-текст.
- Для карточки сохранить isBookmarked, добавить явную кнопку и состояние pending, обновлять только после успешного API; возвращённый результат проверять по epoch и версии запроса. Из раздела закладок удалять через тот же API.
- При открытии вкладок передавать активность персональным экранам, загружать при активации. При возврате из чтения обновлять список принудительно с действующим фильтром, обновлять персональные списки после возврата к ним. Сохранить существующие cancellation/version guards.
- Добавить внедрение зависимостей дочерних экранов для интеграционных widget-тестов с тем же FakeTransport; не заменять реальные GUI-проверки тестами.

## Risks / Trade-offs

- [Переиспользование номера] → точная проверка generation и FTN MsgID; отсутствие точного соответствия означает пустой адрес.
- [Повреждённый журнал] → ограниченный разбор, контролируемая ошибка, никакой записи JAM при чтении.
- [Номер изменён после pack] → резервное значение не угадывается; проверка pack требует отдельного решения идентичности.
- [Запросы при смене вкладок/сессии] → existing version/epoch/cancellation guards; тесты ошибок и поздних завершений.

## Migration Plan

Достаточно пересобрать backend/клиент, схема SQLite совместима. Существующие committed операции поддерживаются. Откат бинарников не меняет JAM; настройки FTN остаются прежними. Тестирование — новое изолированное окружение плюс копия старого QA-журнала для восстановления DEF-003.
