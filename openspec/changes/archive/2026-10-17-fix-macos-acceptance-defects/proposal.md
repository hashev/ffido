# Proposal

## Why

Прогон macOS выявил DEF-001–003: отсутствует управление закладками, история остаётся устаревшей, HPT/SMAPI удаляет DADDRESS при перезаписи эхописьма. Нужно исправить все три дефекта и повторить проверки без изменения рабочих FTN-файлов.

## What Changes

- Восстановление отсутствующего адреса получателя из durable журнала подтверждённых отправок при точном совпадении идентичности; существующий JAM-адрес приоритетен.
- Действия добавления/удаления закладок с подтверждением API и обработкой ошибок.
- Обновление истории, закладок и счётчиков при возврате из чтения и переключении вкладок.
- Регрессионные тесты, реальный HPT scan/restart и GUI-перепроверка на копиях, дополнение журнала результатов.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `message-access`: точное резервное чтение адреса после HPT, доступное управление закладками и актуализация персональных экранов.

## Impact

`apps/backend` (MessageService, SQLite journal), `apps/frontend` (список конференций, карточки, персональные экраны), тесты и `docs/manual-test-results.md`. Формат JAM, gRPC-контракт и конфигурации FTN не изменяются. Рабочие базы не используются для записи.
