# Proposal

## Why

Клиент и CI используют Flutter 3.41.6, а ограничения pubspec и lockfile удерживают устаревшие зависимости. Сервер распространяется архивами, но для установки через Docker отсутствуют образ и публикация в `hashev/ffido`.

## What Changes

- Обновить Flutter до последнего stable на момент реализации, зафиксировать точную версию во всех сборках и согласовать встроенный Dart с SDK constraints клиента и `tools/proto`.
- Обновить прямые и транзитивные Dart-зависимости до последних стабильных совместимых версий, включая major-обновления и необходимые миграции. Для оставшихся ограничений SDK/пакетов представить проверяемые причины без принудительных overrides.
- Добавить воспроизводимую многостадийную сборку сервера из корня CMake в Linux Docker-образ для `linux/amd64`, включая необходимые библиотеки, admin/helper/wrapper и лицензии.
- Добавить проверку запуска контейнера на синтетических данных, подключение внешних конфигурации/TLS/FTN/постоянного состояния и инструкцию эксплуатации.
- Добавить публикацию проверенного образа в Docker Hub `hashev/ffido` в существующем процессе релизов: версия prerelease и SHA для master, версия stable и `latest` для стабильного тега. PR только проверяет образ.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `release-distribution`: проверяемый актуальный Flutter toolchain и зависимости; дополнительный серверный Docker-артефакт, его эксплуатационный контракт и правила публикации.

## Impact

Затронуты `apps/frontend/pubspec.yaml`, lockfile, при необходимости Dart-код и платформенные конфигурации, `tools/proto/`, `.github/workflows/`, `scripts/release/`, Dockerfile и `.dockerignore` в корне, документация. Сервер собирается через существующие CMake и закреплённые native-зависимости; их массовое обновление не входит в задачу. gRPC/HTTP-контракт и форматы пользовательских данных сохраняются. Архивные пакеты и существующая матрица платформ остаются обязательными. ARM64-контейнер, Web-шлюз и встроенный запуск HPT как отдельного сервиса не входят в объём.
