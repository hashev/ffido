# Proposal

## Why

Последовательное чтение сейчас открывает все соседние письма и останавливается на границе эхи. Пользователь хочет читать только непрочитанные сообщения с продолжением в следующей эхе и использовать уже выбранное изображение как иконку FFIDO.

## What Changes

- Кнопки перехода в обычном режиме EchoArea пропускают прочитанные сообщения, включая страницы без непрочитанных.
- После исчерпания непрочитанных текущей эхи «Следующее» открывает первое непрочитанное следующей доступной эхи в порядке исходного списка; эхи без новых писем пропускаются.
- Порядок и фильтр исходного списка фиксируются на время чтения; конец списка завершает обход без зацикливания. Цепочки и другие типы областей сохраняют текущий режим.
- Иконки Android, iOS, macOS, Windows и Web заменяются производными сгенерированного изображения золотистой собаки с синей дискетой на тёмно-синем фоне; Linux получает ту же иконку окна в существующем runner.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `message-access`: последовательная навигация по непрочитанным сообщениям эх и переход между эхами в порядке исходного списка.
- `platform-runtime`: единая иконка приложения на поддерживаемых платформах.

## Impact

- `apps/frontend/lib/pages/message_screen.dart`, `reader_app.dart`, `personal_conferences.dart`, соответствующие widget-тесты; при необходимости локальная модель контекста обхода.
- Платформенные ресурсы `apps/frontend/{android,ios,macos,windows,web,linux}` и общий исходник иконки в `apps/frontend/assets/branding/`.
- `apps/backend/` и `contracts/ffido/v1/ffido.proto` не требуют изменений: списки уже содержат `is_read`, API предоставляет страницы и актуальные сведения об области. Новые зависимости и миграции не планируются.
- Сохранение общего списка сообщений и возможности вручную открыть прочитанное письмо; изменение касается последовательного листания эх.
