# Spec Delta

## ADDED Requirements

### Requirement: Единая иконка FFIDO
Приложение SHALL использовать выбранное пользователем изображение золотистой собаки с синей дискетой на тёмно-синем фоне как иконку Android, iOS, macOS, Windows и Web и как иконку окна Linux там, где её показывает окружение. Платформенные варианты SHALL сохранять пропорции, узнаваемые морду и дискету, обеспечивать необходимые отступы и соответствовать форматам платформы. Исходник SHALL храниться в репозитории без зависимости от локальных каталогов автора.

#### Scenario: Нативные и web-ресурсы
- **WHEN** собираются Android, iOS, macOS, Windows и Web
- **THEN** launcher/AppIcon/ICO, favicon и обычные и maskable web-иконки содержат производные одного выбранного изображения без стандартного логотипа Flutter

#### Scenario: Маска и малые размеры
- **WHEN** иконка показана в малом размере или обрезана системной маской
- **THEN** пропорции сохранены, морда и дискета различимы, значимая часть изображения остаётся внутри безопасной области

#### Scenario: Чистая копия проекта
- **WHEN** иконки подготавливаются или приложение собирается из чистой копии репозитория
- **THEN** все исходные и платформенные ресурсы доступны без обращения к Downloads или каталогам Codex

#### Scenario: Linux
- **WHEN** Linux-приложение запускается из собранного bundle в окружении, поддерживающем иконку окна
- **THEN** используется та же иконка, загружаемая из bundle без зависимости от текущего рабочего каталога
