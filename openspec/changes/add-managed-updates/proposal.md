# Proposal

## Why

Сейчас обновление FFIDO требует вручную найти, скачать и заменить клиентские и серверные пакеты. Нужен простой сценарий по образцу Telegram: приложение сообщает о новой версии и предлагает обновиться одной кнопкой, а оператор управляет обновлением сервера командами.

## What Changes

- Фоновая проверка и ненавязчивое уведомление в клиенте, ручная проверка, загрузка с прогрессом, установка и перезапуск с сохранением профилей; для macOS ad-hoc допускается запрос Keychain или повторный вход. Приоритет удобства — Android и macOS; Windows/Linux входят в матрицу.
- Проверяемый подписанный источник обновлений поверх существующих GitHub Releases и release-manifest.json; выбор платформы, архитектуры и канала stable/dev, защита от случайного downgrade.
- Android использует системный установщик APK; macOS — Sparkle 2 с сохранением sandbox и координацией независимых профилей.
- Сервер получает команды версии, проверки, скачивания, применения и допустимого отката полного серверного комплекта. Обновление не запускается автоматически при обычном старте.
- Docker обновляется отдельной командой на хосте через Compose с закреплением digest, сохранением mounts и проверкой готовности.
- Документированный переход со старых ручных установок и тесты обновления между двумя сборками.

## Capabilities

### New Capabilities

- `client-updates`: обнаружение обновлений, уведомления и управляемая установка клиента.
- `server-updates`: команды обновления обычного сервера и Docker, сохранение состояния и восстановление при сбоях.

### Modified Capabilities

- `release-distribution`: подписанные метаданные обновления и установочные артефакты, пригодные для обновления существующих установок.

## Impact

Затрагиваются apps/frontend/lib, нативные runners Android/macOS/Windows/Linux, apps/backend/src/main.cpp и серверная упаковка, scripts/release, .github/workflows/release.yml и build.yml, docs/docker.md и руководства установки. Добавляются закреплённый Sparkle 2 и минимальные библиотеки проверки подписи/загрузки по необходимости. Существующий TLS gRPC API не меняется; версии приложения и совместимость протокола не отождествляются. iOS/Web, магазины приложений, delta-пакеты и безусловная фоновая установка сервера вне объёма. Приватные ключи подписи поставляются через защищённое окружение выпуска.
